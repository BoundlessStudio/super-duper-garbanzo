# Repository Guidelines

## Project Structure & Module Organization
`src/` holds application code for this TanStack React Start app. Routes live in `src/routes` and are file-based; `src/routes/__root.tsx` defines the shared layout and `src/routes/index.tsx` is the home route. Router setup is in `src/router.tsx`. The generated route manifest is `src/routeTree.gen.ts` (do not edit by hand). Shared utilities belong in `src/lib` (e.g., `src/lib/utils.ts`). Global styles are in `src/styles.css` and Tailwind CSS is enabled. Static assets live in `public/`. Tooling/configuration lives in `vite.config.ts`, `tsconfig.json`, and `components.json` (shadcn/ui).

## Build, Test, and Development Commands
- `pnpm dev` — start the Vite dev server on port 3000.
- `pnpm build` — create a production build.
- `pnpm preview` — serve the production build locally.
- `pnpm test` — run the Vitest test suite.
- `pnpm lint` — run Biome lint checks.
- `pnpm format` — format code with Biome.
- `pnpm check` — run Biome’s combined checks (lint + format verification).

## Coding Style & Naming Conventions
Formatting and linting are enforced by Biome (`biome.json`): tabs for indentation and double quotes in JavaScript/TypeScript. Use `.tsx` for React components and keep route filenames aligned with URL paths (e.g., `src/routes/about.tsx` maps to `/about`). Component names should be PascalCase; utility functions should be small and named for intent. Avoid editing `src/routeTree.gen.ts`; it is regenerated by the router tooling.

## Testing Guidelines
Testing is set up with Vitest and React Testing Library (see `package.json`). When adding tests, prefer colocated files such as `Component.test.tsx` alongside the component or in a `src/__tests__` folder. Keep tests focused on behavior and user-visible outcomes.

## Commit & Pull Request Guidelines
The existing commit history is informal (short, descriptive messages). Keep commit messages concise and action-oriented; add a brief scope when helpful (e.g., “router: add settings route”). For PRs, include: a short summary, testing steps (commands run), and screenshots or recordings for UI changes. Link related issues if applicable.
